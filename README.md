# History — دانشنامهٔ تاریخ و اندیشه

History آرشیوی مستقل و منبع‌محور برای مطالعهٔ تاریخ جهان، تاریخ معاصر ایران، زندگی شخصیت‌های اثرگذار و تاریخ اقتصاد است.

## اصول تحریریه
- تفکیک واقعیت مستند، دیدگاه منتسب و تحلیل.
- ارجاع ادعاهای مهم به منابع قابل‌بررسی.
- ثبت تاریخ انتشار و آخرین بازبینی.
- نمایش اختلاف روایت‌ها بدون تبدیل دیدگاه به واقعیت قطعی.
- پرهیز از پیش‌بینی قطعی بر اساس شباهت‌های تاریخی.
- ثبت اصلاحات و تغییرات محتوایی.

## ساختار
- `index.html`: صفحهٔ اصلی
- `assets/style.css`: طراحی واکنش‌گرا
- `assets/app.js`: جست‌وجو و فیلتر آرشیو
- `data/index.json`: فهرست عمومی و قابل‌خواندن توسط ماشین\n- `data/articles/*.json`: پرونده‌های مستقل با شناسهٔ پایدار\n- `data/schema.json`: قرارداد ساختاری داده‌ها\n- `llms.txt`: راهنمای خواندن آرشیو برای سامانه‌های هوش مصنوعی\n- `article.html`: قالب نمایش مستقل هر پرونده
- `sitemap.xml` و `robots.txt`: پایهٔ فنی سئو

## معماری داده
محتوای اصلی در فایل‌های متنی و ساختاریافتهٔ همین مخزن نگهداری می‌شود. پایگاه دادهٔ عملیاتی مستقل History فقط برای صف پردازش، شناسه‌ها، وضعیت بررسی، زمان‌بندی و فراداده استفاده خواهد شد؛ نه برای ذخیرهٔ متن کامل دانشنامه. پروژهٔ Moon Shop جدا می‌ماند و هیچ تغییری در آن انجام نمی‌شود.

## وضعیت
این نسخه اسکلت اجرایی اولیهٔ سایت است. عنوان‌های آغازین، پرونده‌های پایه‌اند و مقالهٔ تکمیل‌شده محسوب نمی‌شوند. هر مقاله پس از پژوهش و بررسی منابع منتشر خواهد شد.
