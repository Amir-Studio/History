# History — دانشنامهٔ تاریخ و اندیشه

History آرشیوی مستقل و منبع‌محور برای مطالعهٔ تاریخ جهان، ایران، اقتصاد و شخصیت‌های اثرگذار است.

## اصول تحریریه
- تفکیک واقعیت مستند، ادعای منتسب، تحلیل و عدم‌قطعیت.
- ارجاع هر ادعای مهم به منبع قابل‌ردیابی.
- ثبت زمان انتشار رویداد و زمان دریافت جداگانه.
- سنجش استقلال گزارش‌ها؛ بازنشر یک خبر چند منبع مستقل نیست.
- کشور محل انتشار به‌تنهایی معیار بی‌طرفی یا صحت نیست.
- ثبت اختلاف روایت‌ها و اصلاحات بدون پاک‌کردن ردپای قبلی.
- هیچ رکورد تولیدشده توسط هوش مصنوعی خودکار تأیید نمی‌شود.

## ساختار اصلی
- `index.html`: صفحهٔ اصلی آرشیو
- `research.html`: میز جست‌وجوی چندمنبعی در GDELT، Crossref و Wikidata
- `news.html`: نمایش آرشیو خبرها، ادعاها، منابع و اختلاف روایت‌ها
- `assets/`: کد رابط کاربری و سبک‌ها
- `data/index.json`: فهرست پرونده‌های پژوهشی
- `data/articles/*.json`: پرونده‌های مستقل با شناسهٔ پایدار
- `data/news/*.json`: رکوردهای خبری مستقل
- `data/prices/*.json`: مشاهدات قیمت مستقل
- `data/research-methodology.json`: پروتکل ارزیابی منابع
- `data/quality/feedback.json`: اصلاحات بازبینی‌شده توسط انسان
- `data/quality/evaluation.json`: وضعیت سنجش دقت
- `llms.txt` و `ai-index.json`: راهنمای ماشین‌خوان
- `sitemap.xml` و `feed.xml`: کشف محتوا

## عامل پژوهش هوش مصنوعی
`scripts/research-agent.mjs` با OpenAI Responses API و ابزار جست‌وجوی وب کار می‌کند. گردش‌کار `.github/workflows/history-research.yml` فعلاً دستی است و برای اجرا به secret خصوصی `OPENAI_API_KEY` در GitHub نیاز دارد. کلید هرگز در کد عمومی یا مرورگر قرار نمی‌گیرد.

عامل خبرهای عمومی Dollar را فقط از endpoint عمومی می‌خواند، موارد دارای ارزش تاریخی را با جست‌وجوی وب بررسی می‌کند و رکوردهای منتخب را با وضعیت `pending_review` به این مخزن اضافه می‌کند. این عامل به جدول‌های Supabase پروژهٔ Dollar/Moon Shop دسترسی نوشتن ندارد و هیچ داده‌ای را حذف نمی‌کند.

**هزینهٔ OpenAI API جدا از اشتراک ChatGPT است.** تعداد نامزدهای هر اجرا محدود شده است؛ قبل از اجرای مکرر، میزان مصرف و سقف هزینهٔ API را بررسی کنید.

## یادگیری از خطا
فقط اصلاحاتی که انسان بررسی و تأیید کرده باشد در `data/quality/feedback.json` قرار می‌گیرد و به‌عنوان مثال در اجراهای بعدی استفاده می‌شود. این روش بازخورد و بهبود دستورالعمل است، نه آموزش خودکار وزن‌های مدل. دقت تا زمان ارزیابی مجموعهٔ ثابت و برچسب‌خورده توسط انسان، «اندازه‌گیری‌نشده» باقی می‌ماند.

## وضعیت محتوا
پرونده‌های اولیه تا تکمیل پژوهش و بررسی منابع، در وضعیت draft می‌مانند. ابزار جست‌وجو سرنخ می‌دهد؛ خودش حقیقت را تأیید نمی‌کند.
